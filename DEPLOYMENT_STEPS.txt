ENDOWMENT PAYOUT RISK MODEL — QUICK DEPLOYMENT

1. Create a GitHub repository.
2. Upload:
   - app_annual_hybrid_v3_stress.py
   - endowment_model_annual_hybrid_v3_stress.py
   - requirements.txt
   - README.md
   - .gitignore
3. Sign in to Streamlit Community Cloud.
4. Connect your GitHub account/repository.
5. Create/Deploy an app.
6. Select app_annual_hybrid_v3_stress.py as the main file.
7. Deploy.
8. Open the generated *.streamlit.app link.
9. Set the app to private or public in Streamlit sharing settings as appropriate.
10. Share the link with approved users.

Users then upload the required D1/D2 Excel files in the browser and run the model.

Version note: this package is the V3 structured-stress Python model and does not yet include the newer R1 nine-portfolio Excel integration.
